# 🏢 SAMYAK - Corporate Communication Hub

**SAMYAK** is an AI-assisted web prototype designed to address key organizational communication challenges, streamline cross-departmental coordination, and eliminate accountability gaps in corporate environments.

---

## 📌 Project Overview
This project was developed for the **Corporate Communication** course to demonstrate how centralized web interfaces can reduce communication friction and establish operational transparency across enterprise departments.

### 🎯 Key Problems Solved
* **WhatsApp Dependency & Fragmentation:** Replaces informal chat threads with structured digital sign-offs and central status reporting.
* **Accountability Gap:** Features an interactive assignment module ensuring clear ownership, assigned priorities, and hard deadlines for key tasks.
* **Ops-Sales Misalignment:** Live status sync to ensure sales teams quote stock availability accurately without delays.
* **Unified Event Management:** Single source of truth for hospitality, registration, and guest coordination.

---

## 🛠️ Key Features
* **Executive Overview Dashboard:** Gives managers high-level metric cards, urgent alerts, and daily intimations.
* **Digital Approval Desk:** Features dynamic digital sign-offs for financial release requests.
* **Task Accountability Tracker:** Interactive ownership assignment tool for incoming operational tasks.
* **Ops-Sales Sync & Leave Intimations:** Live tracking of product availability and leave handovers.

---

## 💻 Tech Stack
* **HTML5** (Semantic Structure)
* **CSS3** (Responsive Layout, Custom Variables, Flexbox/Grid)
* **JavaScript (Vanilla)** (Tab navigation, interactive status updates, dynamically updated date display)
* **AI Assistance:** Developed with prompts & guidance via Google AI Studio / Gemini.
